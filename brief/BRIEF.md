# Бриф: стиль (этап 1)

## 1. Задача

- **Продукт / бренд:** «Мука» — вымышленная крафтовая пекарня-кондитерская (малое производство, акцент на ремесленность). Проект для портфолио: бренд существует только на сайте.
- **Цель сайта:** вкусно продать — показать продукт так, чтобы захотелось прийти и купить; для автора проекта — продемонстрировать уровень дизайна и анимаций (ориентир — awwwards).
- **Целевое действие:** прийти в пекарню — адрес, часы работы, маршрут (вымышленные).
- **Аудитория:** локальная, РФ; заходят и с телефона, и с компьютера — продуманный опыт на обоих.
- **Как поймём, что получилось:** сайт выдерживает сравнение с референсами уровня awwwards; бюджеты производительности в норме; все гейты этапов пройдены.

## 3. Стиль

- **Выбранное направление:** «Гастрономический разворот»
- **Настроение (три прилагательных):** аппетитное, журнальное, крупное.
- **Свет и цвет:** светлый; тёплая кремовая «бумага» вместо чистого белого; контраст строится на масштабе — огромные фотореалистичные крупняки корки и мякиша против плотной крупной типографики, как разворот гастрономического журнала.
- **Характер:** яркий, но не кричащий; вкус делают фото и вёрстка, а не украшения.
- **Плотность анимаций:** умеренно — медленный параллакс фото, проявление текста по скроллу, одна горизонтальная глава (меню как разворот). Зачем: анимация ведёт взгляд по «развороту», но не перекрикивает продукт.

Отклонённые направления (коротко, почему):
- «Постерная лавка» — смелее нужного: цветовые блоки и стикеры перетянут внимание с продукта на оформление.
- «Мука в луче света» — слишком тихое для задачи «вкусно продать»: созерцание не приводит в пекарню.

Референсы — `references/`; что берём из каждого:
- Tartine Bakery — ремесленная история бренда, крупные цитаты, тёплый тон.
- Gjelina — сдержанность, крупная фотография как главный герой.
- Supermoon Bakehouse — смелость подачи и сочность (точечно, не как основа).
- Josey Baker Bread — человеческий, честный тон текстов.
- Flour Bakery + Cafe — функциональная ясность блока «где найти».

Антиреференсы:
- «Милашки-пекарни» с рукописными шрифтами и пастельной палитрой — не то.
- Каталожно-корпоративная подача с сеткой одинаковых карточек.

Тест «тот же шаблон»: журнальная вёрстка построена вокруг конкретных текстов и масштаба конкретных кадров — с чужим контентом развалится (сетка, ритм, длина заголовков).

## 4. Технологии

- **Стек:** Astro — одна страница-лендинг, контент меняется редко, статика; React-острова только где нужно.
- **Стили:** CSS Modules — авторская журнальная вёрстка, много кастомных стилей и анимации; токены — CSS-переменные.
- **Анимация:** GSAP + ScrollTrigger (скролл-сцены, параллакс, горизонтальная глава), Lenis — один smooth scroll на сайт (по скиллу `lenis-scroll`), Motion — для микровзаимодействий, если появятся React-острова.
- **3D:** нет. Если идея появится по ходу — через `DECISIONS.md`.
- **CMS, формы, i18n, аналитика:** нет CMS, нет форм, только русский, аналитика не нужна (портфолио).
- **Персональные данные:** нет → 152-ФЗ не касается.
- **Хостинг:** VDS пользователя; без Cloudflare (аудитория РФ); домен — не определён.
